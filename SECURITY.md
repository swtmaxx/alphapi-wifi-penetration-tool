# Security Policy

## Intended use

Use this firmware only on networks and devices that you own or are explicitly
authorized to test. The project can capture Wi-Fi management and EAPOL frames,
send deauthentication frames, and start rogue access points. Those functions
can interrupt other users and may be unlawful without authorization.

## Reporting a security issue

Please do not publish credentials, PCAP files, full-flash images, private
firmware, or device logs containing personal data in a public issue. Open a
private GitHub security advisory when available, or contact the repository
maintainer through the GitHub profile before disclosing details.

Remove the default management AP password and any test credentials from your
local configuration before deploying the firmware.
